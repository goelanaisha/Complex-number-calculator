
# Complex Number Calculator

## Project Overview
The Complex Number Calculator is a C++ based application that performs basic arithmetic operations on two complex numbers.

It demonstrates object-oriented programming concepts such as classes, objects, constructors, member functions and operator overloading.

## Objectives
- Create a Complex class with real and imaginary parts.
- Initialize complex numbers using constructors.
- Overload +, - and * operators.
- Display results in a readable a + bi format.

## Features
- Addition of two complex numbers.
- Subtraction of two complex numbers.
- Multiplication of two complex numbers.
- Handles positive, negative and zero values.
- Displays results in a readable format.

## Technologies Used
- Programming Language: C++
- Concepts: Object-Oriented Programming
- Compiler: g++

## OOP Concepts Demonstrated
- Classes and Objects
- Constructors
- Operator Overloading
- Member Functions
